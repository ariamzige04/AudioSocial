\# AudioSocial - Decisiones técnicas



\## Arquitectura



Frontend:



Expo + React Native + TypeScript.



Backend:



Supabase.



\## Base de datos



PostgreSQL administrado mediante Supabase.



Las tablas accesibles por el cliente deben protegerse mediante RLS.



\## Autenticación



Supabase Auth.



Los usuarios deben confirmar su correo electrónico.



\## Archivos



Los audios y recursos de usuario se almacenan mediante Supabase Storage.



\## Desarrollo



Los cambios deben ser incrementales.



No se debe regenerar una pantalla o módulo completo si el problema puede resolverse con una modificación pequeña.



\## IA



Las herramientas de IA se utilizan como asistencia de desarrollo.



El proyecto, repositorio, decisiones y commits pertenecen a sus colaboradores humanos.



La IA no se registra como autora ni coautora de los commits.
